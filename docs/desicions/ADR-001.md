# ADR 001: Uso de `LinkedBlockingQueue` para la Ingesta de Datos

## Estado
Aceptado

## Contexto
El simulador debe manejar múltiples flujos de precios que llegan asíncronamente. Es necesario un mecanismo que desacople la recepción de los datos de su procesamiento para evitar la pérdida de información durante picos de carga.

## Decisión
Hemos decidido utilizar `LinkedBlockingQueue` como el buffer central entre los productores (Price Feeds) y el consumidor (Trading Engine).

## Justificación
- **Sincronización Nativa**: Proporciona la seguridad de hilos necesaria sin requerir la implementación manual de `wait()` y `notify()`.
- **Control de Flujo (Backpressure)**: Al definir una capacidad máxima, la cola impide que el sistema consuma toda la memoria RAM si el motor de decisiones es más lento que los productores.
- **Eficiencia**: Ofrece una complejidad de $O(1)$ tanto para la inserción como para la extracción de elementos.

## Consecuencias
- El sistema introduce una latencia mínima debido al bloqueo de la cola, la cual es insignificante comparada con la estabilidad ganada.
