# ADR 003: Uso de `CompletableFuture` para la Ejecución de Órdenes

## Estado
Aceptado

## Contexto
La generación de una orden de trading puede implicar tareas lentas (como escribir en un log de auditoría o enviar una petición de red). Si el motor de decisiones espera a que la orden se complete, dejaría de procesar la entrada de precios.

## Decisión
Implementaremos la ejecución de órdenes mediante `CompletableFuture.runAsync()`.

## Justificación
- **No Bloqueante**: Permite disparar la ejecución de la orden en un hilo separado y continuar inmediatamente con la evaluación del siguiente precio.
- **Componibilidad**: Permite encadenar acciones posteriores (ej: enviar notificación tras la ejecución) de forma declarativa y limpia.

## Consecuencias
- Introduce la necesidad de gestionar correctamente la finalización del programa para asegurar que todas las tareas pendientes en el pool de hilos se completen antes del cierre.
